![main_view](/pictures/view.png)

## Installation

1. Deploy [**package/token**](https://github.com/emepi/nivra-court) in the test environment and copy coin type to `src/constants.tsx`.
<br><br>
2. Deploy [**package/nivra**](https://github.com/emepi/nivra-court) in the test environment and copy package id and registry id to `src/constants.tsx`.
<br><br>
3. Deploy [**package/contract_kit**](https://github.com/emepi/nivra-court) in the test environment and copy package id to `src/constants.tsx`.

## Starting your dApp

To install dependencies you can run

```bash
npm install
```

To start your dApp in development mode run

```bash
npm run dev
```
